Politique de confidentialité de Kontan

Dernière mise à jour : 15 octobre 2026.

Qui sommes-nous

Kontan est une application de facturation pour les chauffeurs VTC, éditée par RIDE SERVICES, 203 rue André Karman, 93300 Aubervilliers (SIREN 805 365 376). Contact : commercial@ride-services.com.

Vos données restent sur votre téléphone

Kontan n'a pas de compte et pas de serveur. Votre profil, vos clients, vos factures, devis et avoirs sont enregistrés uniquement sur votre téléphone. Nous n'y avons pas accès.

Ce qui part sur internet, et pourquoi

  • Le nom d'une entreprise cliente, quand vous le tapez, part vers l'annuaire officiel des entreprises (recherche-entreprises.api.gouv.fr, service de l'État) pour retrouver son SIREN et son adresse.
  • Les adresses de départ, d'arrêt et de destination d'une course partent vers le service de cartes de l'État (data.geopf.fr, IGN) pour calculer la distance.
  • Le nom d'un lieu (un hôtel, un restaurant), si vous touchez « Chercher par son nom », part vers OpenStreetMap (nominatim.openstreetmap.org).

Ne partent jamais : vos montants, vos IBAN, les noms de vos passagers, vos factures.

Sauvegarde

Quand vous exportez une sauvegarde, c'est vous qui choisissez où ranger le fichier (iCloud Drive, votre ordinateur…). Ce fichier n'est pas chiffré : gardez-le en lieu sûr. Votre code de verrouillage n'y figure jamais.

Verrouillage

Si vous activez Face ID ou un code Kontan, la vérification se fait sur votre téléphone. Votre code n'est jamais enregistré en clair.

Pas de publicité, pas de revente

Kontan n'affiche pas de publicité et ne vend aucune donnée.

Combien de temps

Vos données restent sur votre téléphone tant que l'application y est installée. La loi impose aux entreprises de conserver leurs factures 10 ans : pensez à exporter une sauvegarde régulièrement.

Vos droits

Vos données étant sur votre téléphone, vous les gardez, les exportez ou les supprimez vous-même (en supprimant l'application). Pour toute question : commercial@ride-services.com. Vous pouvez aussi vous adresser à la CNIL (cnil.fr).
